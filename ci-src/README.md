# ci-src

Слепок CI-части репозитория-потребителя: пути внутри повторяют пути в корне
проекта, куда эти файлы копируются.

Исключение одно — сегмент типа проекта (`npm/`, `nuget/`, `docker/`) при
копировании выбрасывается: на один целевой `.github/workflows/ci.yml`
претендуют три разных источника. Об этом же написано в `README.md` каждого
каталога типа и в шапке каждого файла.

- полный перечень путей — [docs/copy-map.md](../docs/copy-map.md);
- правила оформления и порядок сверки с живым репозиторием —
  [docs/conventions.md](../docs/conventions.md).

Каталог не в корне намеренно: у шаблонов настоящие триггеры (`push`,
`schedule`, `release`), и в корневом `.github/workflows/` они запускались бы
здесь.
