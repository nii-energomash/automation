# Экшены только для Gitea

Композитные действия, которым площадка GitHub не пригодится: они обращаются к
API Gitea или к окружению её раннера.

| Экшен | Что делает |
| --- | --- |
| `docker-cli` | ставит docker CLI и плагин buildx в образ задания |
| `registry-cleanup` | удаляет технические образы из реестра Gitea |
| `release-upload` | прикрепляет файлы к релизу — аналога `gh` у площадки нет |
| `nuget-sources` | собирает список источников NuGet под реестр Gitea |

То, что обязано совпадать у обеих площадок, лежит в
[`.ci/actions/`](../../.ci/actions).

Файлы отсюда копируются один в один в `.gitea/actions/<name>/`
репозитория-потребителя. Назначение каждого — в
[`docs/actions.md`](../../../docs/actions.md).
