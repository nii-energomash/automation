# docker, Gitea

Файлы этого каталога кладутся в `.gitea/workflows/` репозитория-потребителя:
сегмент `docker/` при копировании выбрасывается.

`ci-python.yml` и `ci-dotnet.yml` — два варианта одного и того же
`.gitea/workflows/ci.yml`: берётся тот, что подходит языку проекта, второй не
копируется. Модель релиза и дельта площадок — в
[`docs/docker.md`](../../../../docs/docker.md).
