# Общие экшены

Композитные действия, одинаковые для GitHub и Gitea. Каталог экшена копируется
один в один в `.ci/actions/<name>/` репозитория-потребителя, вызывается как
`uses: ./.ci/actions/<name>`.

| Экшен                                            | Что делает                                        |
| ------------------------------------------------ | ------------------------------------------------- |
| [`prepare-npm-release`](prepare-npm-release)     | версия из тега в `package.json` и выбор dist-тега |
| [`prepare-nuget-release`](prepare-nuget-release) | проверка релизного тега и версия для `-p:Version` |
| [`version-from-tag`](version-from-tag)           | проверка релизного тега и версия сервиса          |

Подробнее — в [docs/actions.md](../../../docs/actions.md).

Каталог не привязан к площадке намеренно: обе площадки читают экшен по
относительному пути из рабочего каталога, поэтому одна копия обслуживает оба
зеркала и не даёт им разъехаться.

Площадочный экшен, если такой появится, кладётся не сюда, а в
`../../.github/actions/` или `../../.gitea/actions/`.
