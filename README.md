# automation

Референс CI/CD-конфигураций для проектов организации. Отсюда **копируют**:
в целевом репозитории размещается копия воркфлоу, действия или конфига, а не
ссылка сюда.

Прежний подход — подключение воркфлоу и действий отсюда по `uses:` — прекращён.
Его срез лежит в ветке [`v1`](../../tree/v1) и релизе
[`v1.0.0`](../../releases/tag/v1.0.0). Это архив: он не развивается и
потребителей туда не переводят.

Наполнение приезжает по шагам. Порядок работ, целевая раскладка каталогов и
правило копирования —
в [#31](https://github.com/nii-energomash/automation/issues/31).
